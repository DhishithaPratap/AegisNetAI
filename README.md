TDFISI AI is an AI-enhanced network security monitoring and intrusion detection platform built using Python.

The project simulates:

TCP/IP traffic
DNS activity
Firewall events
IDS/IPS detections
SIEM-style alert correlation
It also integrates machine learning for anomaly detection and threat analysis.
